# 从逆向资料到独立工程

依据：引用会话 `01a1a4a2-c08a-76a2-a594-b6973206a3fa` 中的技术文档、核心代码导读和后续六项工程建议；原资料采样日期为 2026-11-04。原资料的文件指纹另存于 `validation/source-manifest.json`，便于回查版本。

## 1. 证据与工程选择

| 原资料中的机制 | 原定位 | 本工程处理 | 性质 |
|---|---|---|---|
| App 对象绑定应用身份 | C02、C03 | `Driver.target` + Main 允许列表，动作不接受 app 参数 | 独立设计 |
| `nodeRepl.rpc("sky", ...)` | C04、C05、C14 | 具名 Electron IPC → Session → Driver | 替换专属运行时 |
| 策略 → 用户授权 → canonical target | C06 | Main 固定允许的 bundle id；原生 helper 再检查唯一进程 | 参考机制，缩小范围 |
| getter 输入固定与复制 | C06 | `record / parseAction / parseAct` 拒绝 accessor、未知字段，复制冻结嵌套 ref | 独立实现，超出原版浅冻结范围 |
| 原生版本握手、串行请求、pending Map | C07、C08 | 自有 `cu-reference/1`、会话队列、JSONL 请求 id | 新协议，不兼容 Sky |
| 原生 4 字节 LE 分帧 | C08 | 私有 stdin/stdout JSONL，按字节缓存并限长 | 有意更换协议 |
| AX 文本 + 可选截图 | C09、N、D | v1 实现 AX 完整观察；截图能力为 false | 保留观察核心，截图后续补齐 |
| 索引随完整刷新变化 | D01 | 每次 observe 生成新 snapshot UUID；每个动作消耗快照 | 更保守的独立策略 |
| 进程/页面/loader 变化时拒绝旧元素 | 原生原型、B01–B04 | session/snapshot/PID/launchDate/单窗口校验；浏览器仅设计 | 已实现原生子集 |
| Stop/Interrupt 生命周期 | P01、P02 | Main 生命周期事件 + `Session.cancel()` + helper 退出等待 | 独立实现 |
| 任务说明动态注入 | C13 | 契约中显式能力对象；模型层应按能力生成文档 | 能力对象已实现；模型层未接入 |
| socket peer 认证 | H01、H02 | 主进程直接拉起私有子进程，不开放 socket；本地路径固定 | 改用较小攻击面，不复用其可信链 |
| 浏览器 AX/DOM-only、认领 tab | C11、C12、B01–B04 | 保留扩展说明，首版无浏览器实现 | 后续阶段 |

`C/B/N/D/H/P` 是上一轮材料中的证据编号；原文的“原生符号线索”“待验证”仍保持相同证据等级。本轮没有继续反编译原生服务，也没有把新的实现方式追认为 Codex 的实现细节。

## 2. 不可直接搬入的依赖

| 专属依赖 | 为什么不能直接运行 | 自有替代 |
|---|---|---|
| `globalThis.nodeRepl`、`rpc`、`nativePipe` | 宿主提供的桥和权限上下文 | Electron Main IPC + 自有 helper |
| trusted services 与 trusted code paths | 配置本身不赋予可信进程身份 | 自有发布身份、固定受信模块、私有子进程 |
| Sky socket、`CodexComputerUseIPC-5` | 协议耦合并受进程认证保护 | `cu-reference/1` + 私有 stdio |
| `createElicitation` 与组织策略 | 属于宿主产品服务 | Main allowlist + 本次会话授权；组织策略未来独立实现 |
| 浏览器宿主访问代理和 claimTab | 绑定用户会话、扩展与宿主 | 自有 BrowserDriver、tab lease 和 origin policy |
| AX WASM、原生 Guardian 等产物 | 实现与分发边界不同；没有完整源码证据 | 自有观察/引用机制；首版无锁屏能力 |

工程内不引入 `@oai/cua`、`@oai/sky`、Codex 的二进制、令牌或 socket 路径。打包内容为本轮独立代码及其正常 npm 依赖；旧提取材料继续作为分析对照资料。

## 3. 从核心代码阅读到工程文件

推荐依次阅读：

1. `src/shared/contracts.ts`：先建立边界、数据与能力模型。
2. `src/shared/validation.ts`：确认 TS 之外的运行时约束。
3. `src/main/index.ts`、`manager.ts`：确认谁可以发起会话和操作哪个目标。
4. `src/automation/session.ts`：理解快照、队列、截止时间、取消与租约关系。
5. `src/drivers/macos/jsonl-client.ts`：理解分片、请求关联、断线与退出。
6. `native/MacAXBridge.swift`：核对真实 AX 元素引用和动作路径。
7. `tests/` 与验证记录：确认每个结论的实际验证层级。
